What nanoGit does, in one paragraph

It writes your folder a README so it explains itself, adds a list of things to leave out, and then keeps a copy of the folder every time you press a button called Save a checkpoint. That copy lets you go back to how things were last Tuesday. When you want to, one more button puts the whole thing on GitHub so you can share it or get it back if your computer dies.

Checkpoint = commit History = repository Put it online = push Things to leave out = .gitignore

What "private" means here

A private repository can only be seen by you. A public one can be read by anybody on the internet, including anything you forgot was in the folder — which is why private is the default, and why nanoGit stops if it finds something that looks like a password.

Find your folder

Click a folder to go into it. When you are looking at the right one, press Use this folder.

Settings

The name and address written on every checkpoint. Only used to say who saved it — it is not an account, and nothing is sent anywhere.
