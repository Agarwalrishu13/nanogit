What nanoGit does, in one paragraph

It writes your folder a README so it explains itself, adds a list of things to leave out, and then keeps a copy of the folder every time you press a button called Save a checkpoint. That copy lets you go back to how things were last Tuesday, or pull out a single file you deleted by mistake. When you want to, one more button puts the whole thing on GitHub so you can share it, or get it back if your computer dies.

What "private" means here

A private repository can only be seen by you. A public one can be read by anybody on the internet, including anything you forgot was in the folder — which is why private is the default, and why nanoGit stops if it finds something that looks like a password.
